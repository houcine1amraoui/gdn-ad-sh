# gdn-ad-sh

## Raw Data Folder Structure

In the root directory of the project, create this folder "data/raw" and put put the BRMaster.csv and CUMaster.csv files inside. Otherwise, you can change the name and place of raw data folder in the config.yaml file or via terminal command args.
Put the BRE_filtered_columns.txt and CU_filtered_columns.txt files in this raw data folder as well.
